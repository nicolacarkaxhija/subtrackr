# @subtrackr/domain

## 0.1.0

### Minor Changes

- Initial v1 (web). Subscription tracking with a smart catalog quick-add, full lifecycle
  CRUD, multi-currency spend totals with base-currency conversion via bundled rates,
  shared-plan splitting, free-trial countdowns, cost-per-use, CSV export, and local
  persistence. Built as hexagonal ports and adapters with property and mutation testing on
  the domain core.
